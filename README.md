# FinTrack

A personal finance management system built with **Java 21**, **Spring Boot Microservices**, and a clean **HTML/JS** dashboard. 

# Services:
   * Service Registry (Port 8761)
   * User Service (Port 8082)
   * Expense Service (Port 8081)
   * Budget Service (Port 8083)
   * API Gateway (Port 8080)


## Tech Stack
* **Backend:** Spring Boot, Spring Cloud (Eureka, Gateway, OpenFeign), Spring Security (JWT)
* **Database:** MySQL
* **Frontend:** HTML, CSS, JavaScript, Bootstrap 5, Chart.js

## Features
* JWT-secured user authentication
* Track income and expenses with custom categories
* Monitor real-time spending against budget limits
* Dashboard visualizations (Chart.js)
* Date range filtering and CSV export
